# ChatCodex · 使用说明

让 ChatGPT / Claude 这类网页对话，直接查看并改造你本地的项目代码。

当前版本为 v0.11.3，窗口标题会显示版本号。请使用 `dist/v0.11.3/ChatCodex.exe`，旧版 exe 保留在原位置。

## 用之前

- Windows 电脑，基础文件能力双击即用，**不需要安装 Python**；语义引用和重命名需另配本地语言服务
- 需要能访问外网（走 Cloudflare 隧道）
- 建议开着你的代理，速度会明显更好

## 四步上手

**1. 双击 `ChatCode启动器.exe`**

**2. 选择项目目录**
   点「选择…」，挑你要让 AI 改的那个项目文件夹。运行中也可选择其他目录，或输入目录后点「切换项目」，无需重启隧道。
   文件浏览和编辑工具限制在这个目录内。运行命令时使用你当前的系统账户权限。

**3. 点「启动服务 + 穿透」**
   等大约 **30–40 秒**，界面顶部出现一个 `https://xxx.trycloudflare.com` 开头的地址，就说明通了。

**4. 把地址填进对话工具**
   点界面上的「复制接入步骤」，会复制好完整教程，粘给自己照着填：

   - ChatGPT：设置 → 开启开发者模式 → 新建自定义连接器 → 填地址 → 认证选「无认证」
   - Claude：设置 → 添加自定义连接器 → 填地址

   然后在对话的工具菜单里启用它，直接说你要改什么。

## 建议先试这句

> 看一下项目结构，然后把 README 第一行标题改掉

先确认读写链路通了，再让它做复杂的事。

## 注意事项

- **地址末尾那串随机字符是"钥匙"**，复制时别漏。别把完整地址发到群里或公开场合——拿到的人就能访问你的项目。
- **每次重启，地址都会变**，需要去对话工具里更新一次。
- **用完记得点「停止」**，服务停了公网地址立刻失效。
- 是否确认、是否提供「始终允许」由对话客户端决定；工具会声明只读或修改性质，但不能绕过客户端的确认规则。

## 常见问题

**启动后很久没出地址？**
先看日志区。如果是网络问题，确认代理是否开着；也可以在「代理」栏手动填，比如 `http://127.0.0.1:7897`。

「自动探测」会先读取代理环境变量和 Windows 系统代理地址，再扫描常用端口；日志会注明来源。若系统仅配置 PAC 脚本，需要在此填写代理软件的 HTTP/mixed 地址。仅使用 TUN/VPN 时，系统可能无需单独的本地代理地址。

**提示端口被占用？**
程序会自动换端口，以日志里显示的为准，不用管。

**想换穿透方式？**
界面上有 Cloudflare（默认）、cpolar、frp 可选；后两者需要自行准备对应程序。高级连接设置里可填 frp 服务器和固定公网地址；token 仅保留在本次运行中。

## 查看任务和改动

- 「任务中心」页新建任务、查看和复制恢复包、暂停、恢复或取消，支持分页。
- 「后台进程」页查看模型启动的命令、读取日志或停止选中进程。
- 「文件改动」页查看本服务产生的改动及 diff，或撤销选中改动。文件后来被编辑器改过时，撤销会拒绝覆盖。
- 最近项目和非秘密设置会自动保存；再次启动可从项目目录下拉框选择。

## 更顺畅的代码修改

新版共 50 个工具。可以直接对网页版助手说：

> 先用 project_overview 看项目，用 find_files 和 code_outline 定位，再 batch_read 读取相关代码。用 edit_files 按版本批量修改，返回 diff，运行 run_checks 验证；长任务用 read_process 续读。

- 文件修改保留编码、BOM 和主要换行风格，支持预览、重试去重和撤销。
- Python 类和函数可直接按符号读取或替换；其他语言需要语言服务。
- 可在「高级连接设置」的语言服务命令 JSON 中填 `{"python":["C:/你的Python环境/python.exe","-m","pylsp"]}`，该环境需已安装 `python-lsp-server`。
- 配置后可用 `find_references` 查语义引用、`rename_symbol` 跨文件改名。未配置时引用只返回文本候选，重命名会要求配置服务。
- 关闭命令执行也会关闭语言服务进程；基础文件读写仍可使用。详细配置见 README。

## 安全边界

- 文件工具限制在你选的目录内，遍历时跳过符号链接和 junction；默认 host 模式命令不属于操作系统沙箱；native 模式见下方说明
- 部分明显的破坏性命令会被拦截，正则规则不能代替系统权限隔离
- 修改已有文件必须使用读取时的版本号；冲突时会要求重新读取
- 多文件提交失败会尝试回滚；如果恢复期间发现外部编辑，会保留外部内容并报告冲突
- 注意：被 AI 读取的文件内容会传到对话工具的服务器上，敏感代码请自行判断

## v0.6 正式版新增

- 高级设置可以开启「只读模式」：网页只能读取项目，写入、命令和语言服务进程均禁用。
- 默认不向网页返回 `.env`、私钥和证书容器文件；`.env.example/.sample/.template` 仍可读取。确需访问时，在高级设置勾选「允许访问 .env / 私钥文件」，该项不保存到最近项目配置。
- 可用项目根目录 `.chatcodeignore` 拒绝特定文件或目录；规则在启动时加载，修改后需重启。示例：`confidential/`、`*.local.txt`。不自动读取 `.gitignore`，详细规则见 README。
- 命令和检查支持 `operation_id`：同一网络请求重试不会重复启动。若状态不明，会要求核对日志，而不会自动再执行一次。
- 大 diff 改成分页返回，支持已删除文件和暂存区。网页模型可根据 `next_offset` 与 `diff_revision` 续读。
- GUI 启动状态与就绪地址同步更新。

可以直接对网页助手说：

> 先检查 server_info 的权限和文件策略；命令与检查提供唯一 operation_id，网络重试复用；大 diff 按 next_offset 和 diff_revision 续读；遇到 ACCESS_DENIED 不要通过命令绕过。

默认 host 模式的命令使用当前系统账户权限，文件过滤不是系统沙箱。命令修改文件不会纳入编辑工具的撤销记录；需要时先做好版本管理或备份。

## v0.7 运行中切换项目

项目目录和公网连接已拆开。服务运行中点「选择…」、选最近项目，或输入路径点「切换项目」，原 MCP 地址和认证保持不变。

- 切换时原项目命令继续运行；改动、进程及语言服务仍属于原项目。切回后可以查看原记录。停止整个服务会清理所有项目的后台命令。
- 登记过多个项目后，网页调用必须携带 `workspace_id` 和 `workspace_token`。让网页先调用 `list_workspaces`，核对目标项目并使用其身份；旧对话不能直接把原任务改到新项目。
- 单次连接最多登记 20 个项目。登记项目意味着允许当前连接访问该目录；远程不能自行添加任意目录。
- 项目切换不改变认证、端口、代理和连接级权限。规则及已登记项目配置在本次运行中固定，修改后需重启加载。
- 只解决“换项目不用重连”；退出程序后免费隧道域名仍可能变化。

以上为历史版本修复记录。桌面后端已在后续版本接入，但当前界面隐藏入口并标明“暂不使用”，日常编码无需配置桌面窗口。

## v0.8 任务保存与继续工作

向网页助手说明：

> 先核对项目，再 task_create 保存目标、验收条件和必需检查。后续调用都带项目身份和 task_id，用 task_update 保存进度、决定和下一步。完成前执行检查，用 task_finish 交付。

换对话后，让助手先 task_list 找任务，再 task_context 读取恢复包。也可以在「任务中心」选择任务，点「查看恢复包」后复制到新对话。重启后先核对现场，再恢复任务；不会自动重跑命令或恢复网页聊天记录。

- 任务和项目绑定，切换项目后原任务仍归原项目；不用重新穿透。
- 「暂停」阻止该任务后续修改，已运行命令继续。「取消」停止本服务所属命令，保留已有文件修改。
- 完成前会核对已观察文件是否变化、进程是否结束，以及必需检查是否在最近修改后通过。发现零测试、检查失败、执行结果缺失或旧进程状态不明，会拒绝直接完成。
- 单任务复核上限为 200 个文件、合计 20 MiB、100 个进程，大工作拆成多个任务。恢复包中会说明裁剪；完整旧日志仍受原保留策略限制。
- 验收说明与摘要由对话填写，检查通过不代表所有业务都已正确。任务范围是说明，不是系统沙箱；命令产生的文件修改仍不能用编辑历史撤销。

以上为历史版本的任务基础能力记录，后续新增内容见下方版本章节。

## v0.9 在副本中执行，检查后合入

「任务中心」新建任务默认勾选“在独立文件副本中工作”。也可以对网页助手说：

> task_create 时使用 isolation="copy"，所有读取、修改和命令都携带原项目身份和 task_id；副本中测试完成后 task_finish。用 task_changes 预览，再 task_apply 携带版本和 dry_run=false 合入原项目。需要撤回时先预览 task_revert，再实际执行。

- 任务显示“待合入”表示副本工作已完成，原项目尚未改变。“合入原项目”按钮实际写入，“撤回合入”实际撤回；两者均提供独立预览按钮。
- 命令在副本中正常产生的文件改动也会纳入合入。冲突时不会覆盖原目录；撤回时也会保护后续人工修改。
- 切换项目不重建隧道；旧任务继续使用原项目的副本。重启后不会自动重跑命令，也不会因副本丢失而切回原目录执行。
- 副本不会复制 Git 历史、依赖环境、构建产物或被本地策略拒绝的文件。复制上限 5000 文件、64 MiB，单文件 8 MiB，单次合入最多 200 文件；超限应拆分项目或任务。
- **文件副本不是系统沙箱。** 命令仍使用你的系统账户权限，绝对路径、网络、数据库等副作用无法靠任务撤回恢复。
- 副本暂时不会自动清理；合入后的撤回材料也受原编辑历史的保留上限约束。需要长期保留时应使用自己的版本管理和备份。

以上为历史版本的副本交付能力记录。当前版本的桌面设置入口已隐藏，编码流程无需绑定桌面窗口。

## v0.10 编码后的界面验收（可选）

本版复用 Windows-MCP 的 UI Automation 能力，帮助网页助手查看程序、点击按钮、填写普通编辑框并核对结果。代码理解、重构和测试仍由原代码工具与语言服务负责。

1. 先准备独立 Python 3.14 后端：运行 README 中的 `desktop/setup_backend.py` 安装命令。
2. 启动新版服务，点“桌面窗口设置”，填写独立环境的 `Scripts/python.exe`，刷新并选择窗口。
3. 默认仅允许观察；需要操作时勾选输入，再“绑定并激活窗口”。这些授权只在本次运行有效。
4. 让网页助手先 desktop_observe，再 desktop_action，随后重新观察。已绑定窗口支持后台只读观察；输入和点击要求目标窗口位于前台，切换前台后需重新观察。其他项目、过期控件、用户接管及状态不明的重试会被拒绝。
5. 主窗口“暂停桌面”随时停止，网页不能自行恢复。需要恢复时在本机重新绑定。

默认不启用桌面能力，原代码工具照常使用。桌面动作影响真实应用，不属于任务文件副本，也不能整批回滚。首版支持控件点击与普通编辑框全文设置；不支持的窗口或控件会明确报错。

升级后请更新网页连接器的工具列表，以看到新增的四个 desktop_* 工具。本机 HTTP 图片传输已经验证，具体网页客户端能否把截图交给视觉模型仍需在该客户端验证。

验收情况：源码与此前 v0.11 测试包的真实输入、点击后重新观察及本机 HTTP 链路已通过；真实浏览器与公网协议探测均已收到 600×330 PNG。最终包加入后台只读观察修复，已通过模块一致性与后台执行回归；重建后的输入/点击复验由用户停止，未计为通过。实际 ChatGPT 网页会话的工具调用与模型视觉理解仍未完成验收。各项结果见随包 verification.json。

## v0.11 使用新增能力

新版共 50 个工具，不依赖 Docker。直接使用本版 exe 即可使用内置 Python 和 Windows 原生执行隔离。

1. Java/Go：在“高级连接设置”点击“检测并填入 Java / Go 语言服务”。没安装服务时仍可读代码和查看声明候选；真实引用与跨文件重命名须配置 gopls / JDT LS。Java 使用常见 Maven/Gradle 项目，不需要 Eclipse 编辑器；服务缓存放项目外，默认关闭 `.project`、`.classpath`、`.settings` 的根目录生成。
2. 大项目：先让助手 `refresh_index`，如 complete=false 继续调用；查符号用 `find_symbol`，节省上下文用 `context_pack`。返回的 Java/Go 声明候选不等于真实语义引用。
3. 长期任务：任务中心可归档、查看归档、导出历史与预览清理。清理会永久删除已归档任务副本，包括未合入修改；任务历史与已合入撤回凭证保留。实际执行前会展示具体计划，网页工具也须携带预览版本。
4. 原生沙箱：高级设置将执行模式从 host 改为 native，再启动服务。使用独立副本任务；命令缺少副本或隔离失败时直接拒绝，不退回本机。内置 Python 标准库可直接用，其他项目依赖/编译器仍需按项目准备。
5. native 用 Windows AppContainer 限制私有文件访问，配合 Job 控制进程树、内存、CPU 和超时。v0.11.1 已允许公网出站联网；回环连接仍遵循 Windows 策略，未自动添加系统豁免。它不是虚拟机，Windows 公开只读资源仍可能可见。原生模式不启动宿主语言服务/Git/桌面输入。
6. 容量预算默认每项目副本 2048 MiB，在创建/启动前检查；不是运行时硬磁盘配额。查看详情可让助手调用 `storage_status`、`language_status`、`index_status`、`sandbox_status`。

浏览器 PNG 验收使用自建本机验收页，不能替代所有网页客户端的视觉模型验收。旧连接服务不会自动升级；关闭旧服务后使用本版 exe，再在网页客户端重连或刷新工具列表。
